Générer des codes d’accès

Cet outil fabrique des codes à remettre à vos clients, et l’empreinte de chaque code à coller dans assets/js/config-brigade.js. Tout se passe dans votre navigateur : rien n’est envoyé nulle part, et personne ne peut retrouver un code à partir de son empreinte.

1. Créer des codes

Copiez ces lignes dans la liste empreintes de config-brigade.js — le guide de lancement montre exactement où. Gardez les codes eux-mêmes dans un endroit sûr (une note, un tableur) : un code perdu ne se retrouve pas.
